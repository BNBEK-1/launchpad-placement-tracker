# Launchpad — Placement Prep Tracker

A clean, lightweight placement and internship tracker for students. Keep applications organized, see your progress at a glance, and build a steady interview-prep habit.

## Features

- Track opportunities by company, role, status, application date, and next step
- Filter by status and search by company or role
- Dashboard counts for active applications, interviews, and offers
- Add and check off interview-preparation tasks
- Responsive layout for desktop and mobile
- Saves data in your browser with local storage; no account or server required

## Run locally

No package installation or build step is needed. Clone or download this repository and open `index.html` in a modern browser. For the best experience, serve the folder with any static file server, such as VS Code Live Server.

## Tech used

HTML, CSS, and vanilla JavaScript. The project is intentionally dependency-free so it is easy to understand and extend.

## Ideas to extend

- Add a calendar view and reminders for follow-ups
- Export and import application data as JSON or CSV
- Add interview notes and company research links
- Move from local storage to a backend with user accounts

## Privacy

All application and checklist data stays in the browser's local storage. Clearing site data in the browser will remove it.
